# Fabrication

本仓库包含三个独立模块，保持各自边界：

- [Rhino AI Harness：WorkBuddy 仓库操作入口](rhino-ai-assistant/docs/WORKBUDDY.md)：从本仓库源码构建 Windows 候选、加载 Rhino 插件，并逐项记录实机验收。不需要聊天附件或额外二进制 ZIP。当前 Stage 1 完整实机验收仍未通过，工程状态为 **REVIEW**。
- [cladding-delivery](cladding-delivery/README.md)：工程包覆深化与交付总控。
- [cad-fabrication-engineering-v3](cad-fabrication-engineering-v3/README.md)：独立 CAD 工程技能包。

交给 WorkBuddy 时，指定仓库并让它先读 `rhino-ai-assistant/docs/WORKBUDDY.md`。本说明不自动授权安装软件、访问生产图纸、修改系统安全设置或发布工程成果。
