# 工程验收与精度边界

## 精度不是单一的 CAD tolerance

大型建筑深化至少要同时控制：原图质量、坐标/单位、节点做法、主体结构偏差、现场复尺、材料工艺、加工设备精度和安装公差。几何内核的数值精度不能替代这些工程条件。

## 人工节点

- Gate A：包覆范围、材料、节点、分缝/分板及必要制造假设。
- Gate B：现场实测及采用值；复尺变化后重算受影响构件。
- Gate C：可选下单审核；本 Skill 默认只输出 REVIEW 包。

## 展开分类

1. 平面板：内置可直接生成 1:1 外轮廓。
2. 可展曲面：需要项目级几何规则和样件验证。
3. 真正钣金：必须引入 bend radius、K-factor、BA/BD、回弹和设备约束，不允许单纯把 3D 表面 unroll 当成制造坯料。

## 验收建议

在进入生产前建立 Golden Samples，至少覆盖：普通平板、转角、开孔、折边、单曲、异形、典型节点和极限尺寸。对每类样本校验模型、三视图、展开尺寸、BOM、套料及实物加工结果。
